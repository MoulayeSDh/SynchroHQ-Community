# Security policy

SynchroHQ Community is public. Security fixes are currently maintained on the
latest `main` branch; no older release line is supported yet.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in an Issue, Discussion, pull
request, or public post. Use GitHub's **Report a vulnerability** button in the
[Community security advisories](https://github.com/MoulayeSDh/SynchroHQ-Community/security/advisories)
to send a private report to the maintainers. Private vulnerability reporting
is enabled for this repository.

Include the affected version or commit, a concise reproduction, the expected
impact, and a way to reach you. Remove real customer data and live credentials
from reproductions. We will acknowledge a report, assess its impact, and
coordinate remediation and disclosure with the reporter. No response or fix
deadline is promised at this stage.
