# Security policy

SynchroHQ Community is being prepared for publication. Supported versions and
the public vulnerability reporting channel will be announced before release.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in an Issue, Discussion, pull
request, or public post. If you already have access to this private repository,
contact its maintainers through an established private channel. Maintainers can
coordinate a private GitHub security advisory in the repository's Security area.

Include the affected version or commit, a concise reproduction, the expected
impact, and a way to reach you. Remove real customer data and live credentials
from reproductions. We will acknowledge a report, assess its impact, and
coordinate remediation and disclosure with the reporter. No response or fix
deadline is promised until a supported-version policy is published.

Before Community becomes public, maintainers must configure and test a private
reporting route available to people outside the repository, then replace the
interim instructions above with that route.
