# Identité visuelle minimale SynchroHQ

Symbole : quatre nœuds autour d’un centre, reliés par des branches et des arcs de synchronisation. Aucun emblème national. Le mot Synchro reste marine ; HQ est bleu/cyan. Assets SVG, favicon et manifeste de l’application disponibles dans `community/frontend/public`.

| Usage | Couleur |
|---|---|
| Navigation et fond institutionnel | `#062d46` |
| Texte principal | `#102c42` |
| Action principale | `#0065de` |
| Accent de marque cyan | `#00a9f4` |
| Nœuds et statut positif | vert ; statuts `#14754b` |
| Fond d’application | `#f3f7fb` |
| Surface | `#ffffff` |
| Erreur | `#a32631` |

Police système locale avec prise en charge arabe, sans dépendance réseau. Espacements de 8px, surfaces arrondies de 14px, cibles interactives d’au moins 44px, focus visible. Les statuts combinent texte et couleur ; le réseau ajoute une indication explicite en plus du point coloré.

Les propriétés CSS logiques adaptent la disposition au RTL. Le mot de marque reste LTR. Les animations respectent `prefers-reduced-motion`. Le lien d’évitement permet d’atteindre directement le contenu.
